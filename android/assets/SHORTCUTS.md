# Atajos de teclado

Los atajos salen de `qml/Main.qml`. salvo los indicados, no actúan mientras escribes en un campo de texto.

Tres atajos se cambian en **Ajustes > Atajos**: «Alternar letra» (`shortcutLyrics`, por defecto `L`), «Cola» (`shortcutQueue`, `Q`) y «Pantalla completa» (`shortcutFullscreen`, `F11`). Pulsa el botón de la tecla actual, pulsa la tecla nueva y se guarda al instante en la configuración. `Escape` cancela la captura; «Restaurar» vuelve al valor por defecto. El atajo capturado deja de actuar mientras esperas la tecla, para no disparar la acción dos veces.

| Atajo | Acción |
|---|---|
| `Ctrl+,` | Abre o cierra Ajustes. |
| `Ctrl+Espacio` | Abre o cierra el lanzador. |
| `Espacio` | Reproduce o pausa. |
| `Right` | Avanza 5 segundos. |
| `Left` | Retrocede 5 segundos. |
| `Ctrl+Right` | Siguiente canción. |
| `Ctrl+Left` | Canción anterior. |
| `Up` | Sube el volumen. |
| `Down` | Baja el volumen. |
| `M` | Silencia o reactiva el sonido. |
| `S` | Activa o desactiva el orden aleatorio. |
| `R` | Activa o desactiva la repetición. |
| `[` | Retrasa la letra 0,1 segundos. |
| `]` | Adelanta la letra 0,1 segundos. |
| `Ctrl+D` | Marca o desmarca «Me gusta». |
| `Ctrl+R` | Vuelve a buscar la letra de la canción actual. |
| `Ctrl+F` | Enfoca la búsqueda de la cola si el panel de cola está abierto; si no, la de la biblioteca; en el cine, copia la letra. |
| `Ctrl+Shift+A` | Añade la canción actual a la cola. |
| `L` (configurable) | Abre o cierra la letra a pantalla completa. |
| `Q` (configurable) | Muestra u oculta la cola. |
| `Tab` | Muestra u oculta el panel lateral (cola/letras activo). No actúa con Ajustes o el lanzador abiertos. |
| `F11` (configurable), `F12` | Activa o desactiva la pantalla completa. |
| `F` | Abre o cierra la letra a pantalla completa (modo cine). |
| `Ctrl+L` | Abre o cierra la letra a pantalla completa; funciona incluso al escribir. |
| `Ctrl+K` | Va a la búsqueda y enfoca el campo. |
| `Escape` | Vuelve a la vista anterior o cierra el panel abierto. |
| `Back` | Atrás en teléfonos Android. |
